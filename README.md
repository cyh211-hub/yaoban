# 遥伴 Yovolpen

让已适配的蓝牙遥控器成为 Mac 的语音与快捷操作入口。面向桌面智能体、AI 编程和日常办公。

## 功能

- 自定义遥控器按键到键盘组合或鼠标操作，支持短按、长按及连发。
- 按遥控器保存和加载预设。
- Apple 圆盘触控可用作鼠标、滚动等操作。
- 把遥控器语音送入虚拟麦克风，由用户选择的输入法识别文字。

已适配小米蓝牙遥控器 2 Pro、Apple Siri Remote 第三代 USB-C；不代表兼容所有蓝牙遥控器。AI 眼镜尚未适配。
