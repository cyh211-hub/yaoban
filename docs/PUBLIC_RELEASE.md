# 遥伴 Yovolpen 0.10.8（26）公开测试候选

此版本为公开材料整理版本：以用户确认可用的 0.10.6 安装修正版为基础，改用用户确认的 AI 生成遥控器插画，移除官方产品照片；更新第三方声明并提供完整 Opus 源码及构建步骤。按键、触控与语音逻辑未主动改动。

升级和回退使用独立的 0.10.8 备份目录，不占用 0.10.6 的回退资料。不要删除旧应用后安装。

平台范围为 Apple Silicon / macOS 26。没有 Developer ID 签名或 Apple 公证，更新可能需要重新开启权限。安装脚本仍依赖 Apple Command Line Tools 提供的 Python。Apple 遥控器语音需用户自行安装官方 PacketLogger，其他麦克风可继续使用。

## 验证范围

0.10.6 安装修正版：用户确认安装和基本功能正常。
0.10.8：构建、文件和安装包检查结果由随包验证记录列明；尚未在新机器完整验收安装/卸载，也尚未获得本版本实物遥控器验收。不能以 0.10.6 的反馈代替本版本验证。

不宣称支持所有 Mac、所有遥控器或所有系统版本。
