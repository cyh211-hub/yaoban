## Release 标题

遥伴 0.10.5 测试版：让蓝牙遥控器成为 Mac 的语音与快捷操作入口

## 一句话介绍

遥伴是一款面向桌面智能体与日常办公的 macOS 输入辅助软件，可把已适配的蓝牙遥控器变成语音输入、快捷键和触控操作入口。

## 本版亮点

- 小米蓝牙遥控器 2 Pro（RC003）：支持语音输入与已适配按键操作。
- Apple Siri Remote 第三代 USB-C 版：支持按键、长按、触控板和自定义映射。
- 可把遥控器按键映射为键盘组合、鼠标操作和常用工作流。
- Apple 遥控器语音输入作为可选高级功能提供，不影响其他主要功能使用。

## Apple 语音功能说明

Apple 遥控器的语音链路目前需要用户自行从 Apple 官方下载并安装 PacketLogger。PacketLogger 属于 Apple 的 Additional Tools for Xcode，遥伴不会随安装包附带、镜像或重新分发。

未安装 PacketLogger 时，Apple 遥控器的按键、长按、触控和自定义映射仍可使用；仅 Apple 遥控器语音功能不可用。小米遥控器语音与其他主要功能不受影响。

## 测试版提示

- 这是开发中的测试版本，适合愿意反馈问题的早期用户。
- 当前尚未完成 Developer ID 签名与 Apple 公证，不应按正式发行版宣传。
- Apple 遥控器删除后重新配对时，触控与语音恢复稳定性仍需进一步验证。
- AI 眼镜为未来适配方向，目前仅作概念展示。
