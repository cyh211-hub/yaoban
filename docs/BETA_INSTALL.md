# 遥伴测试版安装指南

本指南同时适用于 Gitee 与 GitHub Release。请只从项目正式仓库下载标有“测试版”的文件，并核对 Release 页面公布的文件名和 SHA-256。

## 安装前确认

- 当前公开测试计划优先面向 Apple Silicon Mac；最终系统版本范围以对应 Release 说明为准。
- 小米蓝牙遥控器 2 Pro / RC003 可使用按键映射和遥控器语音。
- Apple Siri Remote USB-C 第三代可使用按键、长按、自定义映射和圆盘触控。
- Apple 遥控器语音是可选高级功能。无需该功能时，不必安装 PacketLogger。
- 现阶段尚无 Developer ID 签名和 Apple 公证，公开测试包还未生成；项目完成签名状态核对后才会在 Release 提供下载。

## 安装步骤

1. 在 macOS“系统设置 → 蓝牙”中配对遥控器。
2. 从项目 Release 下载测试版安装包，并核对 Release 中的 SHA-256。
3. 如果已经运行遥伴，先从菜单栏退出，再安装新版本。
4. 打开遥伴，按系统提示允许蓝牙、输入监控和辅助功能。
5. 在遥伴的设备页面添加已经配对的遥控器，并确认当前使用设备。
6. 选择一个内置预设开始测试，或按自己的习惯修改按键、长按、键鼠组合和圆盘触控设置。
7. 需要遥控器语音时安装“遥控器麦克风”组件，再在输入法或目标应用中选择“遥控器麦克风”。

## Apple 遥控器语音

只有 Apple 遥控器语音需要额外安装 Apple PacketLogger。完整步骤见[可选组件说明](APPLE_VOICE_OPTIONAL_SETUP.md)。未安装时：

- Apple 遥控器语音不可用；
- Apple 按键、长按、自定义映射和圆盘触控仍可使用；
- 小米遥控器按键与语音仍可使用；
- 其他不依赖 Apple 语音的功能不受影响。

## 升级、卸载与反馈

- 升级前退出遥伴。测试版可能要求重新授予输入监控或辅助功能权限。
- 删除并重新添加 Apple 遥控器后，如果触控或语音状态异常，请重开遥伴并在 Issue 中附上版本、macOS 版本、遥控器型号和复现步骤；不要公开上传包含设备地址或原始蓝牙内容的日志。
- 若 Release 提供专用回退包，必须使用与该版本匹配的回退包。回退可能撤销升级后新增的设置。
- 提交问题前先阅读[已知限制](KNOWN_LIMITATIONS.md)和[隐私说明](../PRIVACY.md)。
