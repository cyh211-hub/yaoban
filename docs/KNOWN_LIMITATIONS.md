# 遥伴测试版已知限制

更新：2026-09-13。此列表用于代码托管平台测试版首发，Release 发布时按对应构建重新核对。

## 发布与系统范围

- 当前源码版本为 0.10.5（23）。现有候选安装包仍把 PacketLogger 当成整个安装包的前置检查，不符合公开测试版方案，不能直接上传为首发 Release。
- 当前没有 Developer ID 签名和 Apple 公证。面向普通用户的正式分发需要完成签名、公证和安装验证。
- 目前主要开发与实机验证环境是 Apple Silicon / macOS 26。早期主体功能以 macOS 14 为最低目标，但公开测试包的最终系统范围必须由该包重新验证。

## 设备与功能

- 小米蓝牙遥控器 2 Pro / RC003 已适配；其他小米型号不能按外观或名称推定兼容。
- Apple Siri Remote USB-C 第三代是当前 Apple 测试型号；其他代际尚未开放。
- Apple 电源键不开放映射，因为现阶段无法可靠阻止系统睡眠行为。
- Apple 电量在没有可信读数时显示“暂未读取”，不会以 0% 代替。
- 圆盘触控、轻点、滑动和外环旋钮仍需要持续扩大实机回归；系统更新可能影响所使用的触控入口。
- 删除 Apple 遥控器后重新添加，可能出现触控板或语音状态不稳定；这是首发前继续修复和重点回归的问题。
- 自定义媒体键映射已在当前开发机实测，但不能据此保证所有 macOS 版本、应用或事件来源行为一致。

## Apple 遥控器语音

- Apple 遥控器语音是可选高级功能，当前需要用户自行从 Apple 官方渠道安装 PacketLogger。
- PacketLogger 是 Apple 专有工具，遥伴不能捆绑、镜像或重新分发。
- 底层系统蓝牙诊断可能经过其他蓝牙设备流量；遥伴只选择当前绑定遥控器的有效语音帧进入解码。
- 完整链路已在开发机完成 Apple 遥控器 → 遥伴 → 虚拟麦克风 → 输入法实测；长时间运行、断连恢复、删除重加和更多系统版本仍需测试。
- Apple 语音当前依赖系统诊断和管理员后台组件，系统更新可能改变可用性。

## 输入与第三方软件

- “语音输入”指遥伴把遥控器声音送入虚拟麦克风。语音识别、文字输入和智能体任务执行由目标输入法或应用负责。
- “全部按键自定义”指已适配型号在遥伴中开放的映射能力，不包含设备固件保留的配对或电源操作。
- 各输入法、桌面智能体和办公软件的快捷键、麦克风选择与兼容性需要逐项实测。

提交新问题时，请提供遥伴版本、macOS 版本、Mac 架构、遥控器准确型号、当前预设、预期结果和复现步骤。公开 Issue 中不要粘贴完整设备地址、原始 HCI 数据、原始音频或含私人内容的日志。
