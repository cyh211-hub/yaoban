# 遥伴测试版发布检查清单

## P0：通过后才能上传安装包

- [ ] 重新构建公开测试包，使 PacketLogger 只作为 Apple 语音的可选依赖；未安装 PacketLogger 时，安装与启动不得失败。
- [ ] 在没有 PacketLogger 的干净环境验证：软件安装、启动、小米遥控器语音、遥控器按键、Apple 遥控器按键/长按/触控、自定义映射。
- [ ] 在用户自行安装官方 PacketLogger 后验证 Apple 语音完整链路。
- [ ] 验证 Apple 遥控器删除、重新配对、切换设备和重启后的按键、触控与语音恢复。
- [ ] 确认安装包名称、应用版本、构建号、回退包和更新说明一致。
- [ ] 确认公开包不包含 PacketLogger、Additional Tools for Xcode 或其他 Apple 专有文件。
- [ ] 替换或取得 `Assets/Devices` 中厂商产品图片的公开分发权利；在权利范围确认前，不把该图片和依赖它的公开构建作为 Release 发布。
- [ ] 确认公开包不包含诊断日志、试听录音、设备地址、个人配置、密钥、证书或本机路径信息。
- [ ] 生成并公布安装包 SHA-256。
- [ ] 对最终安装包完成一次独立安装和卸载验证。

## P0：发布页必须明确

- [ ] 标题和正文标注“测试版”。
- [ ] 写明当前签名与公证状态；未完成时不得写“正式发行”“开箱即用”或类似承诺。
- [ ] 写明已验证的设备型号和 macOS 范围。
- [ ] 写明 Apple 语音依赖官方 PacketLogger，且该组件不会随遥伴分发。
- [ ] 写明未安装 PacketLogger 时仍可使用的功能。
- [ ] 链接安装说明、Apple 语音设置、已知限制、隐私说明和开源许可。
- [ ] AI 眼镜只标注为规划或概念展示。

## P1：首发体验

- [ ] 仓库首页首屏能在 30 秒内回答：它是什么、解决什么问题、当前能做什么、如何开始。
- [ ] 上传一张功能总览图、一张清晰软件界面图和一段真实操作演示；概念片明确标注为概念展示。
- [ ] 启用 Bug 与功能建议模板，并给出中文反馈入口。
- [ ] 建立版本更新记录；每项写清用户收益、验证范围和限制。
- [ ] Gitee 作为国内首发入口；GitHub 镜像开放后，在两个仓库首页互相标明镜像关系。

## 当前结论（2026-09-13）

现有 `遥伴-0.10.5-修复版.pkg` 仍在安装前强制检查 PacketLogger，因此属于本地候选包，**尚未达到公开上传条件**。完成可选依赖改造并通过以上 P0 验证后，再生成公开测试包。
